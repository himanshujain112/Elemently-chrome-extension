# Elemently – Chrome Extension

Elemently is a lightweight and easy-to-use Chrome extension that lets you edit or remove elements from any webpage in real time. Whether you're a developer prototyping designs, a student cleaning up content for screenshots, or just someone who wants a distraction-free browsing experience — Elemently gives you full control over any website's content.

## Features

- Edit Text – Click any text element on a page and modify it instantly.

- Remove Elements – Hide or delete unwanted ads, popups, banners, or any HTML elements.

- Minimal UI – Quick toggle to activate or deactivate edit mode.

- No Code Required – Works entirely via point-and-click.


## Use Cases

- Clean up web pages for distraction-free screenshots or reading.

- Prototype UI changes directly in the browser.

- Modify content for presentations, demos, or debugging.

- Prank friends by editing headlines (for educational purposes, of course!).

## Installation

1. Download or clone this repository:

git clone https://github.com/your-username/elemently-chrome-extension.git


2. Open Chrome and go to chrome://extensions/.


3. Enable Developer mode (top-right toggle).


4. Click Load unpacked and select the project folder.


5. The Elemently icon should now appear in your Chrome toolbar.

## Usage

1. Click the Elemently icon in the Chrome toolbar.


2. Toggle Edit Mode on.


3. Click on any element to either:

- Edit its text content (text elements only).

- Remove the element entirely (right-click or UI button depending on implementation).



4. Toggle off to return to normal browsing.
